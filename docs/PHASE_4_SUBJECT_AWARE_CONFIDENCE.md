# Phase 4: Subject-Aware Confidence Baseline

## Overview
We have established that Subject Calibration Drift is the primary failure mode of confidence estimation in MatchNet. Physiological features (variance, spectral entropy) failed to explain this drift.

This phase aims to explicitly model subject identity alongside the decision margin to calibrate confidence probabilities.
